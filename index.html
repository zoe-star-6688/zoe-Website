視差捲動效果

作者：Vineet Kumar

什麼是視差捲動？

視差捲動是一種網頁設計技巧，讓背景的移動速度比前景慢。當訪客向下捲動頁面時，就會產生類 3D 的效果， 增加深度並帶來更沉浸的瀏覽體驗。視差源自光學錯覺：人眼會把靠近的物體看得比遠處更大，因此遠方物體 看起來移動得更慢。這種錯覺長期被應用在不同媒介中，形成更真實的視覺效果。最早可追溯至迪士尼《白雪公主與七矮人》 等傳統動畫，以及《超級瑪利歐》等遊戲。 隨著 CSS 與 HTML 的進步，視差效果也發展成為如今的網頁設計手法。

2007 年，網頁開發者 Glutnix 在部落格上分享了瀏覽器中的早期視差捲動實作，內含 JavaScript 與 CSS 2 的範例與 示範，並支援 Internet Explorer 6 等當時的瀏覽器。直到 2011 年 HTML5 與 CSS 3 出現後，這項技術才在網頁設計圈 迅速普及。支持者認為這是擁抱網頁流動感的簡單方式，也能讓使用者更投入並提升整體體驗。不過，普渡大學於 2013 年 的研究指出：「雖然視差捲動提升了某些使用者體驗面向，但不一定能改善整體體驗。」


為什麼要使用視差圖像？

    設計師嘗試視差圖像的兩大理由如下：

  • 有助於說故事

    視差圖像非常適合敘事。好的設計強調溝通；在設計網站時，我們希望與訪客溝通並講述關於產品、 服務或品牌的動人故事。視差捲動能讓訪客沉浸在獨特的線上體驗中，甚至可以打造單頁式網站， 讓訪客在同一頁面讀完整個故事。

  • 提升使用者互動

    視差圖像可提升使用者互動。在網頁設計中，降低跳出率是重要目標之一。跳出率指的是訪客只瀏覽一頁就 按下返回或關閉分頁的比例。高跳出率會影響搜尋排名，因此任何能降低跳出率的做法都值得嘗試。 精心設計的視差頁面能提供更動態的體驗，讓使用者停留更久。


如果你想在網站加入視差捲動效果，請參考以下建議。

  • 選擇性使用

    視差捲動在特定元素上使用會更有效，而不是所有頁面都啟用。可以用在頁首、標題，或僅用於首頁。 目標是強化設計，而不是分散注意力。

  • 圖片壓縮

    視差捲動會使用多種媒體檔案與 CSS 形狀來營造深度，但不要因為大型圖片而犧牲效能與體驗， 避免載入過慢。

  • 玩色彩

    視差捲動不只關於前景與背景的圖像，也與色彩有關。可以在背景使用較低飽和的色調， 在前景使用更鮮明的色彩，來加強深度感。
